Batch import story (NTS-625): new `neode.rowToProperties(Model, row, { map? })` (also exported as a standalone `rowToProperties(schema, row, options)`) maps one source row — a CSV / JSON / NDJSON record — to the property map `createMany()` / `mergeMany()` take: header renames via `map`, defaults, fakes, transforms, then type conversion through the model schema before validation. Non-throwing: returns `{ ok: true, properties }` or `{ ok: false, errors: ValidationIssue[] }` (every failing check for rule violations; one issue for values the type cannot absorb, such as nested relationship rows). Streaming import needs no new API: parse at the edge with any reader and feed batches of mapped rows to `mergeMany()` — `for await` gives backpressure and each batch commits its own transaction; merges on the model's merge fields keep re-runs idempotent. Recipe: `examples/cookbook/bulk-import.ts`.
